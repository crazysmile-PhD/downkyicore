# DownKyi v1.1.1

v1.1.1 是 v1.1 系列的正式修正版，包含 v1.1.0 的架构、下载、导航与
跨平台改进，并修复该版本发布闸门发现的 Windows 程序退出竞态。

## 重点修正

- 测试资料清理、Avalonia headless session、正式 Host、Dispatcher 与
  SQLite owner 改为可等待且有界的 teardown，避免测试或应用程序结束后
  残留前台执行绪。
- 新增 Assembly Lifecycle Stability Gate，逐组件验证载入、探索、执行、
  teardown 与 OS process exit；PR、main、release 分别执行 3、50、100 轮。
- 生命周期报告保留真实 OS 退出时间、慢阶段证据、一般错误分类与
  marker lock 竞态恢复证明；证据缺失或契约不完整会阻止发布。
- 修复 `//host/path` 图片来源在 Windows 被当成 UNC 路径检查，造成图片
  载入或测试执行异常延迟的问题。
- 发布流程会确认 Git tag 与唯一版本来源 `version.txt` 完全一致。
- aria2 恢复 HTTPS 凭证与主机名称验证；不再允许旧 `UseSsl` 设置或 UI
  将下载降级为 HTTP。旧字段仍可一次性读取，下一次保存时会自动移除。
- 内建 aria2 每次启动使用随机 loopback port 与高强度 RPC secret，Cookie
  与 secret 不再出现在程序命令列；Cookie 只可附加到符合范围的单一任务。
- 非本机自订 aria2 RPC 强制 HTTPS，RPC 不跟随重新导向；TLS 错误会明确
  分类并由六个平台真实 aria2 binary 回归测试保护。

## v1.1 系列功能

- .NET 10、Avalonia 12、Microsoft Generic Host、Microsoft DI、
  CommunityToolkit MVVM 与 typed navigation history。
- Domain 下载状态、事件驱动 bounded channel、分阶段下载 pipeline、
  统一 retry、aria2/内建下载器续传与 FFmpeg/ffprobe 输出验证。
- WBI key 生命周期、播放流 JSON envelope、AI 字幕、SRT 时间码、列表
  URL、收藏夹/投稿搜索、复选与返回状态保留修正。
- 脱敏异步日志、diagnostic bundle、严格分析器、跨平台 CI、API/下载/
  SQLite/Host/XAML 回归测试与逐 RID 套件验证。

## 相容性

- 保留既有 settings JSON、资料目录及 portable mode。
- 保留 legacy SQLCipher SQLite、未完成任务、aria2 GID、partial file
  map、completed segment keys 与续传状态。
- 发布包不包含开发者 Cookie、帐号资料、Config、Logs、Cache、Storage
  或下载资料库。

`v1.1.0` 标签仅保留审计历史，其 draft 已撤回且不是核准发行版。请使用
v1.1.1 或后续版本。
