# DownKyi v1.1.0

> Status: withdrawn draft. The immutable tag is retained for audit history,
> but this build is not an approved release. Use v1.1.1 or later. The draft
> was withdrawn after the tag workflow exposed an intermittent Windows
> test-host foreground-thread teardown defect.

v1.1.0 是一次架构与可靠性版本。它保留既有使用者资料和下载续传相容性，同时重建了应用程式的服务所有权、导航、下载状态与发布防线。

## 重点更新

- 升级至 .NET 10、Avalonia 12、Microsoft Generic Host、Microsoft DI 与 CommunityToolkit MVVM。
- 移除 Prism、DryIoc、EventAggregator、RegionManager、ContainerLocator 和旧字串导航。
- 使用 typed navigation history，修复多层返回、返回箭头、页面状态保留与重复建立页面。
- Domain `DownloadTask` 成为 durable 状态权威；新增、续传与启动恢复以 task id 事件驱动排程。
- 下载 pipeline 拆为六个可测试阶段，并统一 retry、取消、清理、错误分类与状态持久化。
- 修复删除任务残留临时档、重启从零下载、多段 DURL key 冲突、顺序错误及输出无法 seek。
- 多段输出经 FFmpeg 重建时间戳/索引并由 ffprobe 验证；硬体编码失败自动回退 CPU。
- 修复 WBI key 初始化/过期、播放流 JSON envelope、AI 字幕空档与 SRT 毫秒时间码。
- 支援列表 URL、收藏夹/投稿内搜索、复选、清空选择及返回后保留页码/查询/清单。
- 下载速度诊断同时显示 MB/s 与 Mbps；高速模式可配置 aria2 分片与连接数。
- 日志改为脱敏、异步 rolling、retention 与可导出 diagnostic bundle。

## 工程品质

- 全方案启用 .NET `AnalysisMode=All` 与 warnings as errors。
- Windows、Linux、macOS PR CI 执行严格 build、全部测试、格式与依赖稽核。
- CodeQL、秘密扫描、Host/XAML smoke、API contract、fake HTTP、SQLite migration、resume 和 ffprobe seek 测试成为长期门槛。
- 发布包逐 RID 验证 DownKyi、aria2、FFmpeg、ffprobe、Fluent theme、版本与 SHA-256 manifest。

## 相容性

- 保留既有 settings JSON 与 portable/data-directory 规则。
- 保留 legacy SQLCipher 下载资料库迁移与 reopen。
- 保留未完成任务、aria2 GID、partial file map、completed segment keys 与续传状态。
- 发布包不包含开发者 Cookie、设定、Logs、Cache 或下载资料库。

升级前可正常关闭旧版本；若需要回滚，请保留 `%APPDATA%\DownKyi`、`~/Library/Application Support/DownKyi` 或 `$XDG_CONFIG_HOME/DownKyi` 的资料备份。不要在两个版本同时执行时共用同一资料目录。
