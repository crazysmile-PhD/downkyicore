# v1.1.1 Corrective Release Gate

Status: active release candidate

v1.1.1 replaces the withdrawn v1.1.0 draft. It may publish only from one
immutable commit that passes every gate below. A green rerun without a root
fix is not release evidence.

## Lifecycle Acceptance

- The synchronous test-data `ProcessExit` cleanup is absent. Test isolation,
  Avalonia headless session, Host, Dispatcher and SQLite owners have explicit,
  awaited teardown.
- Every test assembly passes isolated load, assembly info, discovery,
  execution, assembly teardown and OS process exit.
- Windows PR, Main and Rehearsal profiles execute 3, 50 and 100 iterations per
  assembly with `-ValidateForensics`.
- The schema 2 machine-readable report preserves phase exit codes, stdout/stderr pollution,
  P50/P95/P99/max, residual processes, general failure/error types and
  marker-aware slow evidence.
- The marker-reader self-test must execute, create positive lock contention,
  recover after release, parse the marker, report no error and pass all
  mutation checks. Missing or inconsistent proof fails closed.
- The residual-child self-test must create an actual child that outlives its
  parent, preserve sanitized identity and a manifest, classify the phase as
  `ResidualChildProcess`, and clean the synthetic tree by PID plus creation
  time. Any real residual child remains a release blocker.
- Slow execution evidence, teardown timing and OS process-exit timing remain
  separate. The five-second slow threshold must not be relaxed. Evidence is
  armed one second before that boundary, and the held-child self-test must
  prove that lead against a non-zero-clamped synthetic threshold.

## Product And Data Compatibility

- Existing settings JSON, portable/data-directory rules and legacy SQLCipher
  SQLite migration remain compatible.
- Unfinished tasks retain task ID, GID, partial-file map, completed segment
  keys, progress, output and resume identity.
- The protocol-relative image fix must not probe `//host/path` through local
  Windows file APIs.
- Production source cannot reintroduce Prism, DryIoc, EventAggregator,
  RegionManager, ContainerLocator, string ViewName navigation or static HTTP
  state.
- Release packages contain no developer credentials, Cookie, account data,
  Config, Logs, Cache, Storage or user database.

## Build And Package Acceptance

- Strict `AnalysisMode=All` Release build, all tests, format, module-boundary,
  dependency, secret and diff gates pass.
- Windows x64/x86, Linux x64/arm64 and macOS x64/arm64 native release gates
  pass on the same commit.
- The manual `build.yml` rehearsal passes before tagging and cannot publish a
  Release.
- Every package contains non-empty DownKyi, aria2, FFmpeg, ffprobe and Fluent
  runtime content. Every package sidecar and manifest hash is verified.
- The tag workflow runs the same gates again before publication.

## Version Contract

`version.txt` is the only project version source:

```text
Version: 1.1.1
FileVersion: 1.1.1.0
AssemblyVersion: 1.1.1.0
Git tag: v1.1.1
```

`script/validate-release-version.ps1` blocks malformed versions and rejects a
tag whose `refs/tags/v<version>` value does not exactly match `version.txt`.
The `v1.1.0` tag remains immutable and its withdrawn draft must not be updated
or republished.

## Completion

Publication is complete only when the exact tagged commit has a successful
tag workflow, the GitHub Release is non-draft, all expected artifacts and
SHA-256 evidence are present, and the withdrawn v1.1.0 draft has been removed
without deleting or moving its tag.
